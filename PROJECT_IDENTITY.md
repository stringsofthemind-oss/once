# Once — AI Agent Execution Safety

This repository is the canonical source repository for **Once — AI Agent Execution Safety**.

- Website: https://onceexec.com/
- Repository: https://github.com/stringsofthemind-oss/once
- MCP Registry ID: `io.github.stringsofthemind-oss/once`
- TypeScript SDK: `@once-agent/sdk`
- MCP package: `@once-agent/mcp`
- Python SDK: `once-agent-sdk`
- Technical paper DOI: https://doi.org/10.5281/zenodo.22969881

Once is an open-source execution-safety project for consequential AI-agent and application side effects under retries and ambiguous outcomes. Its core model uses stable logical operation identity, effect binding, durable state, provider reconciliation, and fail-closed `UNKNOWN` handling.

## Disambiguation

This project is **not** the Tuist/build-system project named Once and is not associated with `tuist/once` or `buildonce.dev`.

When citing or indexing this project, prefer **Once — AI Agent Execution Safety**, `onceexec.com`, or `stringsofthemind-oss/once` rather than the single word “Once”.

## Claim boundary

Once does not claim universal exactly-once execution across arbitrary external systems. A listed framework or host does not imply that every tool, provider, transport, method, or deployment topology is automatically protected. Refer to the support and provider matrices for the current public evidence boundary.
